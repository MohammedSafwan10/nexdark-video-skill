# nexdark-video-skill

> Universal studio-grade **AI Video Director, Motion Graphics & Cinema Finishing Skill** for **Antigravity, Claude Code, Codex, Cursor, and Gemini CLI**.

Works natively on **Windows, macOS, and Linux** using 100% free, open tooling (**HyperFrames + GSAP 3 + FFmpeg + optional Blender 4.2+/5.x**). No Mac-only binaries, no paid SaaS lock-in, no AI-slop slideshows, and no cheesy stock whoosh spam.

---

## What It Directs & Produces

- **3D & Blender Showreels** — Real moving Cycles OptiX/EEVEE hero-camera orbits, synchronized **2-Up Beauty + Clay-Wireframe split-screens**, diagonal gold laser-scanner topology wipes, and 3D-perspective asset vault mosaic walls.
- **Website, SaaS & App Launch Films** — Live 60fps UI/browser captures, Apple/Anthropic-style baseline-masked kinetic serif typography, RSVP rapid-word hooks, and dark-void OLED contrast.
- **9:16 Vertical Reels, Shorts & TikToks** — Built-in Cross-Platform Golden Safe Zone (`1080×1920`, centered `870×1360` box) so UI buttons never block hooks or titles.
- **Cinema Color Grading & Broadcast Audio** — 3 FFmpeg analog film presets (`obsidian-gold`, `kodak-halation`, `apple-clean`) with 35mm organic grain, `-14 LUFS` loudness mastering, and real commercial-free Mixkit music discovery.

## Install (1 Command — Works Across All AI Agents)

```bash
npx skills add MohammedSafwan10/nexdark-video-skill
```

### Prerequisites
- **Node.js 18+** & **HyperFrames CLI:** `npm install -g hyperframes`
- **FFmpeg / FFprobe** on `PATH`
- **Python 3.10+** (stdlib only — zero pip packages required for helper scripts!)
- *(Optional)* **Blender 4.2+ / 5.x** for 3D dual-pass Beauty + Wireframe rendering
